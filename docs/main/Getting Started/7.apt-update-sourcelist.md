# Update the APT Package Source List

Use this guide to refresh the package source list on an ArmSoM board running a Debian-, Ubuntu-, or Armbian-based system. A working source list is required before installing packages or updating the system.

## Before you begin

- Confirm that the board is connected to the internet.
- Use an account with `sudo` permission.
- Back up the current source list before changing it.

```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
```

## Check the current sources

Display the configured repositories and any additional source files:

```bash
cat /etc/apt/sources.list
ls -la /etc/apt/sources.list.d/
```

The release name in the source URL must match the system release. Check it with:

```bash
. /etc/os-release && echo "$PRETTY_NAME"
```

## Refresh the package index

If the configured sources are correct, refresh the package index:

```bash
sudo apt update
```

Install available package updates only after reviewing the output:

```bash
sudo apt upgrade
```

## Troubleshooting

If `apt update` reports a repository error, first verify the board's network connection and system date. Then check that the source URL and release name match `/etc/os-release`.

To restore the previous configuration:

```bash
sudo cp /etc/apt/sources.list.backup /etc/apt/sources.list
sudo apt update
```

Do not mix repositories from different Debian, Ubuntu, or Armbian releases. Doing so can prevent future upgrades or cause package conflicts.
