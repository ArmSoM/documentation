## 1. Introduction
Device-tree overlays apply incremental changes to the base device tree at boot, configuring pin multiplexing, peripherals, cameras and displays. ArmSoM provides the `armsom-overlay` terminal menu, while direct editing of boot configuration files remains available. Both methods require a reboot to apply changes.
<span id="doc-section-2" className="armsom-section-anchor" />

## 2. Supported Images
The menu supports ArmSoM SDK images that include `armsom-overlay` and use `/boot/uEnv/uEnv.txt`, including the corresponding Debian 12 and Ubuntu 22.04 images. It reads the current board's configuration; the screenshots in this section use CM5 as an example.

For Ubuntu images using `/boot/firmware/ubuntuEnv.txt` or Armbian images using `/boot/armbianEnv.txt`, follow the matching manual method in Section 4. Compatibility depends on the image's boot configuration layout, not just its distribution name.
<span id="menu-config" className="armsom-section-anchor" />

## 3. Configure with the armsom-overlay Menu

### 3.1 Open the Menu

Run this command in a desktop terminal, SSH session or serial terminal on the board:

```bash
sudo armsom-overlay
```

When logged in as `root`, run `armsom-overlay` directly. A graphical desktop is not required. The tool reads the current board configuration referenced by `/boot/uEnv/uEnv.txt` and lists its available overlays. The actual configuration filename appears at the top; available options depend on the board's configuration.

Older images may not include this tool. Use a newer image for your board that includes `armsom-overlay`, or configure overlays manually as described in Section 4. Updating only the kernel does not install this userspace tool.
:::

### 3.2 Select Peripherals

`[ ]` means unselected and `[*]` means selected. Check the peripheral model, connector and pin assignment in your product documentation before changing options.

| Key | Action |
| --- | --- |
| Up / Down | Move through the peripheral list |
| Space | Select or deselect the current overlay |
| Tab | Switch between the list and the button bar |
| Left / Right | Move between buttons |
| Enter | Activate the selected button; in the list, move focus to Save without writing the configuration yet |
| Esc | Open the exit review dialog |
| F1 / Ctrl+L | Show help / resize and redraw the interface |

The buttons provide these actions: **Select** returns to the list, **Save** writes changes and stays in the menu, **Help** displays help, and **Exit** opens the review dialog.

For example, on CM5 select `raspberrypi-camera-v2 (imx219-cs0)` for an IMX219 connected to J25, or `armsom-camera-m1 (ov13850-cs1)` for an OV13850 connected to J12. Power off before connecting or changing camera ribbon cables. On other boards, select options matching their connectors.

:::warning Option meanings and pin sharing
Selecting `hdmi-disabled` or `dp-disabled` **disables** that display output. Deselecting an overlay removes its overrides and restores the base device-tree settings; it does not always disable a device. Do not enable options that conflict over pins or controllers. The tool checks only conflicts declared in metadata, so also consult your board's pin assignments.
:::

### 3.3 Confirm, Save and Reboot

1. After selecting your options, press **Esc**, or select **Exit** and press Enter, to open **Review**.
2. Check the changes: `Enable` adds an overlay and `Remove` removes one.
3. Use Left/Right or Tab to select **OK**, then press Enter to save pending changes and exit. Select **Back** to continue editing. Review initially selects Back.

<figure style={{maxWidth: '860px', margin: '1.5rem auto'}}>
  <img src={useBaseUrl('/img/getting-started/armsom-overlay-review.webp')} alt="Review dialog showing the OV13850 camera being enabled; OK saves and exits" width="1576" height="837" style={{width: '100%', height: 'auto'}} />
  <figcaption className="armsom-image-caption">Review the changes, then select OK to save and exit</figcaption>
</figure>

After exiting, run:

```bash
sudo reboot
```

:::info Saving does not apply changes immediately
The tool saves selections by commenting or uncommenting `dtoverlay=` lines in the current board's configuration. They take effect after a reboot. **Back does not undo a save**: changes already written with Save remain. To restore earlier selections, change them back in the menu and save again.
:::

### 3.4 Check the Configuration and Hardware

After rebooting, these read-only commands list the saved selections and validate the configuration and corresponding DTBO files:

```bash
sudo armsom-overlay --list
sudo armsom-overlay --check
```

A successful configuration check does not verify hardware operation. Use [ArmSoM Camera Applications](../Advanced%20Manual/2.armsom-camera.md) to check camera preview, and follow the product and interface guides for UART or other peripherals. If the menu does not fit, enlarge the terminal to at least **80 columns × 20 rows** and press Ctrl+L to redraw it.

## 4. Configure Overlays Manually
### 4.1 Ubuntu 22.04 Image Enable Overlay
- The overlay file of Ubuntu 22.04 image is stored in the path on the board:/boot/firmware/dtbs/rockchip/overlay/*.dtbo
- Find the keyword `overlays=` in the `/boot/firmware/ubuntuEnv.txt` file. The following is an example of using two overlay layers for ArmSoM Sige7.
```bash
overlays=armsom-sige7-camera-imx415-4k armsom-sige7-display-10hd
```
After editing, restart the device to change the overlay settings.

### 4.2 Enable overlay for Armbian images
- The overlay file of the Armbian image is stored in the path on the board:/boot/dtb/rockchip/overlay/*.dtbo
- Find or add the keyword 'overlays=' in the `/boot/armbianEnv.txt` file. The following is an example of using two overlay layers for ArmSoM Sige7.
```bash
overlays=armsom-sige7-camera-imx415-4k armsom-sige7-display-10hd
```
After editing, restart the device to change the overlay settings.

- Armbian images can have overlay files added to them：
Taking the addition of Sige5 UART10 functionality as an example：
```bash
linux-rockchip/arch/arm64/boot/dts/rockchip/overlay$ git remote -v
origin  git@github.com:xxx/linux-rockchip.git (fetch)
origin  git@github.com:xxx/linux-rockchip.git (push)
upstream        git@github.com:armbian/linux-rockchip.git (fetch)
upstream        git@github.com:armbian/linux-rockchip.git (push)
```
Download the `linux-rockchip` to your local system, refer to other dts files related to serial ports in the `arch/arm64/boot/dts/rockchip/overlay` directory, and modify the `KERNELSOURCE` in `config/sources/families/rk35xx.conf` to point to the local code

### 4.3 Enable overlay for ArmSoM-SDK image
- The overlay files for the ArmSoM-SDK image are stored in the following path on the board: /boot/dtb/overlay/*.dtbo
- Open the /boot/uEnv/uEnv.txt file and remove the `#` symbol before the dtoverlay for the reuse function
Below is an example of ArmSoM-Sige7 uEnv.txt:
```bash
armsom@armsom:/boot$ sudo vi /boot/uEnv/uEnvarmsom-sige7.txt
cmdline="earlyprintk console=ttyFIQ0 console=tty1 consoleblank=0 loglevel=7 roott
wait rw rootfstype=ext4"

enable_uboot_overlays=1
#overlay_start

#40pin
#dtoverlay=/dtb/overlay/rk3588-armsom-can1-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-can1-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c0-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c1-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c3-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c7-m3.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c8-m4.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm2-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm3-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm5-m2.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm6-m2.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm7-m3.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm8-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm12-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm13-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm13-m2.dtbo
```
After editing, restart the device to change the overlays settings.

## 5. 40-PIN functional test
Some of the pins on the 40PIN can be reused for multiple functions, which can be configured as needed. For specific pin functions, please refer to the `40 pin header` on the board.

Taking the 11 and 15 pins in the 40PIN on Sige7 to open the serial port function as an example:
- View the serial ports opened by the system
```bash
root@armsom-sige7 :/boot# ls /dev/ttyS*
/dev/ttyS6
```
- Open overlay

The serial ports corresponding to pins 11 and 15 on the 40PIN are UART 7_m1, and the corresponding overlay file is`/boot/dtb/rockchip/overlay/rk3588-uart7-m1.dtbo`.

Edit/boot/armbianEnv. txt file:
```bash
root@armsom-sige7 :/boot# cat armbianEnv.txt
verbosity=1
bootlogo=false
console=both
overlay_prefix=rockchip-rk3588
overlays=rk3588-uart7-m1
fdtfile=rockchip/rk3588-bananapi-m7.dtb
rootdev=UUID=a61c17cd-2e49-4302-879c-6cb86ebf07d1
rootfstype=ext4
usbstoragequirks=0x2537:0x1066:u,0x2537:0x1068:u
```
Only the line `overlays=` has been added here.

Configuration takes effect after restart:
```bash
root@armsom-sige7 :/boot# ls /dev/ttyS*
/dev/ttyS6 /dev/ttyS7
```
:::tip 
The functions in the 40PIN are turned off by default and need to be manually turned on to use

Add configuration in/boot/armbianEnv. txt and restart the Linux system to take effect

If only one function needs to be opened, just fill in one. If there are multiple functions, separate them with spaces after `overlays=`
overlays=uart2-m0 uart3-m1 uart4-m2 uart7-m1

Similar to UART 7-m1 and UART 7-m2, they cannot be used simultaneously
:::
