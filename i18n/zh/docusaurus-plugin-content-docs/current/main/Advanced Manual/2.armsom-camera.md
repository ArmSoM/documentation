# ArmSoM 相机应用

ArmSoM 相机应用适用于所有采用 **RK3588、RK3588S 或 RK3576** 的 ArmSoM 板型。启用对应的摄像头 overlay 后，应用会列出板上实际识别到的 IMX219、OV13850，以及驱动支持的分辨率和帧率。

:::info SDK 默认预装

使用默认配置构建的 Debian 12 arm64 桌面镜像已包含 `armsom-camera` 和 `armsom-camera-desktop`，可直接使用 Cheese、guvcview 或命令行。Server 镜像预装 `armsom-camera`，可通过 SSH 或串口操作。

:::

**Cheese** 适合快速拍照和录像，也可以分别指定照片与视频的分辨率。**guvcview** 适合需要手动选择分辨率和帧率的场景，控制窗口和预览窗口可以分开摆放。

本文以 **CM7S 的 Debian 12 XFCE 桌面**为例。在 Ubuntu 等其他桌面镜像中，可在应用菜单中搜索并打开 **Cheese** 或 **guvcview**，再按本文步骤操作。菜单位置和按钮名称可能随桌面环境或界面语言略有不同。

## 1. 准备摄像头 {#prepare}

1. 关闭开发板电源，插好摄像头排线。启用与接口、传感器对应的设备树 overlay，重启后使配置生效。具体接线和配置请参见对应产品使用手册中的 **MIPI-CSI** 小节。
2. 在 XFCE 桌面，打开 **Applications → Multimedia（应用程序 → 多媒体）**，点击 **Cheese** 或 **guvcview**。在 GNOME 桌面，可从“活动”中搜索应用名称。切换应用前，先关闭正在使用相机的程序。
3. 多摄像头板上，可按名称区分已识别的 IMX219 和 OV13850。同型号摄像头可看名称后的接口或模组编号。AIM7 搭配 AIM-IO 时，编号对应板上的 CAM0 至 CAM3。

<figure className="armsom-doc-figure">

![XFCE 应用程序菜单的多媒体分类中有 Cheese 和 guvcview](/img/advanced_manual/armsom-camera/desktop-menu.webp)

<figcaption>① Applications（应用程序）　② Multimedia（多媒体）　③ 选择要打开的应用</figcaption>
</figure>

:::info 阅读截图

截图保留了应用中的英文按钮名称，便于对照。配有 ArmSoM 相机组件的镜像会显示摄像头名称和驱动提供的采集模式。

:::

在 CM7S 上，两款模组的驱动提供以下采集模式。照片分辨率与预览窗口大小可以分别设置。

| 摄像头 | 分辨率（像素） | 对应最高帧率 |
| --- | --- | --- |
| IMX219 | 3280 × 2464 | 15 fps |
| IMX219 | 1640 × 1232、1920 × 1080、640 × 480 | 30 fps |
| OV13850 | 4224 × 3136 | 7.5 fps |
| OV13850 | 2112 × 1568 | 30 fps |

## 2. Cheese {#cheese}

### 2.1 选择摄像头和分辨率 {#cheese-settings}

打开 **Cheese**，等画面出现。单击右上角的菜单 **① ☰**，选择 **② Preferences（首选项）**。同一菜单里的 **③ Fullscreen** 可以切换全屏。

<figure className="armsom-doc-figure">

![Cheese 右上角菜单中的 Preferences 和 Fullscreen](/img/advanced_manual/armsom-camera/cheese-menu.webp)

<figcaption>打开右上角的 ☰ 菜单。</figcaption>
</figure>

在 **Preferences → Webcam** 标签页，使用下图的三个下拉框。

<figure className="armsom-doc-figure">

![Cheese Webcam 页的设备、照片分辨率和视频分辨率](/img/advanced_manual/armsom-camera/cheese-settings.webp)

<figcaption>① 摄像头　② 照片分辨率　③ 视频分辨率</figcaption>
</figure>

打开 **① Device**。菜单会列出板上识别到的摄像头。本例的两项是 **IMX219 (m01, 4-0010)** 和 **OV13850 (m00, 1-0010)**。选择所需的一项，预览就会切到对应镜头。

<figure className="armsom-doc-figure">

![CM7S 的 Cheese 设备下拉菜单，显示 IMX219 和 OV13850](/img/advanced_manual/armsom-camera/cheese-devices.webp)

<figcaption>① IMX219　② OV13850</figcaption>
</figure>

在同一页分别设置 **② Photo resolution**（拍照分辨率）和 **③ Video resolution**（录像分辨率）。例如用 IMX219 拍全分辨率照片时，选择 **3280 × 2464**。希望录像保留完整视野并达到 30 fps 时，视频选择 **1640 × 1232**。设置好后点击右下角 **Close** 返回预览。

<figure className="armsom-doc-figure">

![IMX219 的照片分辨率下拉列表，包含四种驱动模式](/img/advanced_manual/armsom-camera/cheese-modes.webp)

<figcaption>① 展开照片分辨率，选择要保存的尺寸。</figcaption>
</figure>

:::tip 手动选择帧率

Cheese 在选择视频分辨率时协商帧率。要在菜单里指定具体的 fps，请使用 [guvcview](#guvcview)。

:::

### 2.2 拍照与录像 {#cheese-capture}

选好摄像头和照片分辨率，关闭首选项，回到预览窗口。点击左下角 **① Photo** 切到拍照模式，再点击 **② 快门** 拍一张照片。若启用了倒计时，倒计时结束时拍摄。照片保存后会出现在 **③ 缩略图栏**，双击即可查看。

<figure className="armsom-doc-figure">

![Cheese 的 Photo 模式、快门和拍摄结果](/img/advanced_manual/armsom-camera/cheese-photo.webp)

<figcaption>① 选择拍照模式　② 拍照　③ 查看刚拍摄的照片</figcaption>
</figure>

点击 **① Video** 切到录像模式，再点击中间的录制按钮开始录像。**③ 计时器**会显示已录时长。点击 **② 停止（■）** 结束录像并保存，等视频缩略图出现后即可双击播放。

<figure className="armsom-doc-figure">

![Cheese 录像时的 Video 模式、方形停止按钮和计时器](/img/advanced_manual/armsom-camera/cheese-video.webp)

<figcaption>① 视频模式　② 停止并保存　③ 已录时长</figcaption>
</figure>

:::tip Cheese 的照片和视频保存在哪里？

本文的 CM7S XFCE 镜像把照片和视频都保存在 `~/.gnome2/cheese/media/`。打开文件管理器，按 `Ctrl+L`，粘贴此路径并按回车即可打开。`~` 表示当前桌面用户的主目录。

如果桌面已配置“图片”和“视频”目录，Cheese 默认分别保存到这两个目录下的 `Webcam` 子目录。英文桌面通常是 `~/Pictures/Webcam/` 和 `~/Videos/Webcam/`。

:::

### 2.3 全屏预览 {#cheese-fullscreen}

点击右上角 **☰ → Fullscreen**，或在 Cheese 窗口内按 **F11**。再按一次 **F11** 即可回到普通窗口。更改窗口大小不会改变照片或录像的分辨率。

<figcaption>① 点击右下角按钮退出全屏，或按 F11。</figcaption>
</figure>

## 3. guvcview {#guvcview}

### 3.1 选择摄像头 {#guvc-settings}

guvcview 会打开两个窗口。带 **Image Controls、Video Controls、Audio Controls** 标签的是控制窗口。另一个窗口显示实况画面。先在控制窗口点击 **① Video Controls**，再打开 **② Device**。

<figure className="armsom-doc-figure">

![guvcview 控制窗口的视频控制、设备、分辨率和帧率字段](/img/advanced_manual/armsom-camera/guvc-settings.webp)

<figcaption>① 视频控制　② 设备　③ 分辨率　④ 帧率</figcaption>
</figure>

选择要使用的传感器。切换到另一颗摄像头时，如果弹出 **start new** 对话框，点击 **restart**。guvcview 会重新打开当前实例，预览切换到刚选的镜头。

<figure className="armsom-doc-figure">

![guvcview 的 Device 下拉列表，显示 IMX219 和 OV13850](/img/advanced_manual/armsom-camera/guvc-devices.webp)

<figcaption>① IMX219　② OV13850</figcaption>
</figure>

<figure className="armsom-doc-figure">

![切换设备出现的 start new 对话框，标出 restart 按钮](/img/advanced_manual/armsom-camera/guvc-restart.webp)

<figcaption>① 点击 restart，使用所选摄像头重新打开当前实例。</figcaption>
</figure>

### 3.2 设置分辨率和帧率 {#guvc-mode}

先展开 **Resolution**。例如选择 IMX219 的 **1640x1232**。然后打开上方的 **Frame Rate**，选择 **30/1 fps**（每秒 30 帧）。若选用 **3280x2464**，对应值为 **15/1 fps**。**Camera Output** 可保持为 **NV12**。

<figcaption>① 先选择 1640x1232。</figcaption>
</figure>

<figure className="armsom-doc-figure">

![guvcview 展开的帧率列表，1640x1232 对应 30/1 fps](/img/advanced_manual/armsom-camera/guvc-fps.webp)

<figcaption>① 当前分辨率　② 对应的帧率</figcaption>
</figure>

### 3.3 拍照与录像 {#guvc-capture}

选好摄像头、分辨率和帧率，等预览画面稳定后，在**控制窗口**上方点击 **① Cap. Image (I)** 即可抓取并保存一张照片。要录像，点击 **② Cap. Video (V)** 开始录制，再点击同一位置的 **Stop Video (V)** 结束录制并保存。图中使用 OV13850 的 **2112 × 1568、30 fps** 模式。

:::tip guvcview 的照片和视频保存在哪里？

本例的保存目录是桌面用户的主目录 `/home/armsom/`。在文件管理器中打开“主目录”，即可找到照片 `my_photo-1.jpg` 和视频 `my_video-1.mkv`。如果修改过文件名或保存目录，以控制窗口底部状态栏显示的完整路径为准。

:::

## 4. 命令行（桌面和 Server 镜像） {#server-cli}

桌面用户可直接打开终端，Server 用户可通过 SSH 或串口登录。以下命令可选择摄像头、分辨率和帧率；拍照和录像无需连接显示器。

### 4.1 查看摄像头和可用模式 {#server-list}

```bash
armsom-camera list
```

从输出中选一个摄像头 ID，并查看它支持的分辨率和帧率组合。以下示例使用 CM7S 的 `imx219-m01` 和 `ov13850-m00`。如果 AIM7 上的两颗同型号摄像头分别列为 `cam0` 和 `cam1`，将 `--camera` 后的值换成对应的接口 ID 即可。

### 4.2 拍一张 JPEG 照片 {#server-photo}

用 IMX219 的全分辨率模式拍一张照片，保存到当前用户主目录的 `imx219.jpg`。

```bash
armsom-camera photo --camera imx219-m01 --size 3280x2464 --fps 15 -o ~/imx219.jpg
```

要改用 OV13850，选择它的 ID 和对应模式。

```bash
armsom-camera photo --camera ov13850-m00 --size 2112x1568 --fps 30 -o ~/ov13850.jpg
```

### 4.3 录制 MP4 视频 {#server-video}

用 OV13850 以 2112 × 1568、30 fps 录制 10 秒，命令结束后视频保存在 `~/ov13850.mp4`。`--duration` 的单位是秒。省略此参数时，按 `Ctrl+C` 结束录制并保存。

```bash
armsom-camera video --camera ov13850-m00 --size 2112x1568 --fps 30 --duration 10 -o ~/ov13850.mp4
```

### 4.4 在板端显示器上预览 {#server-preview}

将显示器接到开发板并启用显示输出，再运行以下命令。`--display kms` 通过板端的 DRM/KMS 显示画面，无需启动桌面。通过 SSH 或串口执行时，画面仍显示在开发板连接的显示器上。按 `Ctrl+C` 退出预览。

```bash
armsom-camera preview --camera imx219-m01 --size 1640x1232 --fps 30 --display kms
```

在桌面终端运行同一条预览命令时，省略 `--display kms` 即可使用桌面预览窗口。
