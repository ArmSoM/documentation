# 1. 百度网盘资源介绍

ArmSoM 百度网盘按产品型号整理配套资源，包括硬件资料、软件资料、系统镜像和开发工具，也提供板卡用前必读、质检报告等资料。下载前请先进入对应产品目录，阅读其中的使用说明。

## 1.1 网盘资源概览

网盘中的资料主要用于了解硬件设计、开展软件开发、安装系统和调试设备。各产品目录下的“板卡用前必读”介绍电源、接口连接及首次使用注意事项，建议先阅读；质检报告等配套文件也可在对应目录查找。

[打开 ArmSoM 百度网盘](https://pan.baidu.com/s/14qfAZM3QqgJPuFVjKRSBUw?pwd=arms)，提取码：`arms`。

![ArmSoM 百度网盘产品目录](/img/general-tutorial/baidu-cloud-all.png)

<div className="armsom-image-caption">按产品型号选择对应目录</div>

:::info 资源范围
不同产品提供的资料、系统版本、桌面类型和工具可能不同，以对应产品目录中的实际文件及说明为准。下文用于介绍资源类别，不代表每款板卡都有全部组合。
:::

## 1.2 硬件资料

硬件资料用于了解板卡接口、电路连接和结构尺寸，便于外设连接、底板开发及结构设计。

| 资料 | 主要用途 |
| --- | --- |
| 原理图 | 查看供电、接口和器件之间的电路连接 |
| 尺寸图、DXF 文件 | 确认外形尺寸、安装孔和接口位置 |
| 硬件设计文件 | 参考产品或开发套件的设计，具体文件格式以目录内容为准 |
| 主要器件手册 | 查阅芯片功能、电气参数和接口说明 |

需要在 Altium Designer 中查看 Allegro 设计文件，可参考 [Allegro PCB 导入指南](./allegro-to-altium.md)。

## 1.3 软件资料

软件资料主要包括开发文档和已编译好的系统镜像，用于查阅开发说明、安装系统和部署应用。

| 资料 | 主要用途 |
| --- | --- |

## 1.4 系统镜像

系统镜像是为对应板型编译好的系统文件。下载时先确认产品型号，再选择系统版本和桌面类型。

### 1.4.1 系统版本

| 系统 | 常见版本或标识 | 说明 |
| --- | --- | --- |
| Debian | Debian 11 / `bullseye`；Debian 12 / `bookworm` | 根据产品提供的版本及应用依赖选择；两者的软件包版本不同 |
| Ubuntu | Ubuntu 22.04 LTS / `jammy` | 适合使用 Ubuntu 软件生态的桌面或服务应用 |
| Armbian | 文件名或说明中包含 `Armbian` 及发行版信息 | 基于 Debian 或 Ubuntu，具体版本和支持的板型见产品目录 |
| Android | `Android` 及版本号 | 用于 Android 应用与界面开发，版本以产品提供的镜像为准 |

例如，[Sige6](<../ArmSoM Product/sige6.md>) 的产品文档列有 Debian 11，[CM5](<../ArmSoM Product/cm5.md>) 和 [AIM7](<../ArmSoM Product/aim7.md>) 列有 Debian 12、Ubuntu 22.04。请从自己的产品目录下载。

### 1.4.2 桌面与命令行类型

系统版本和桌面类型是两个独立的选择。例如，Debian 12 表示发行版，XFCE 表示桌面环境。

| 类型 | 常见文件名标识 | 使用场景 |
| --- | --- | --- |
| GNOME 桌面版 | `gnome` | 连接显示器、键盘和鼠标，使用图形桌面与应用 |
| XFCE 桌面版 | `xfce` / `xfce4` | 使用较轻量的图形桌面，兼顾本地操作与资源占用 |
| Server / CLI 命令行版 | `server` / `cli` | 不预装图形桌面，适合通过串口或 SSH 管理设备、部署服务 |

:::tip 如何选择
需要 HDMI 桌面、图形应用或视频预览时，优先选择产品提供的桌面镜像；主要通过 SSH 部署服务时，可选择 Server / CLI。需要桌面效果的教程不能直接假设命令行镜像已装好图形环境。
:::

### 1.4.3 识别镜像文件

镜像文件名通常包含产品型号、系统版本或代号、桌面类型、架构和日期。不同产品的命名方式可能不同，以下用一个历史文件名说明字段含义：

```text
armsom-w3-debian-bullseye-xfce4-arm64-20231115
```

| 字段 | 含义 |
| --- | --- |
| `armsom-w3` | 适用产品型号：ArmSoM W3 |
| `debian-bullseye` | Debian 11（Bullseye） |
| `xfce4` | XFCE 图形桌面 |
| `arm64` | 64 位 ARM 架构 |
| `20231115` | 日期，格式为 `YYYYMMDD`，即 2023 年 11 月 15 日 |

压缩包请按包内说明解压使用。`update.img` 通常是固件升级包，`rootfs.img` 通常是根文件系统分区镜像；仅凭 `.img` 后缀不能判断烧录方式。

:::warning 选择与板型匹配的镜像
请核对产品型号、硬件版本和烧录说明。不要仅凭芯片型号相同就混用不同板卡的镜像，也不要把单独的 `rootfs.img` 当作完整系统固件烧录。
:::

### 1.4.4 下载后怎么用

1. 在产品目录阅读说明，确认板型、系统版本、桌面类型和目标存储介质；如提供校验值，下载后核对文件完整性。
2. 使用对应平台的烧录工具：Rockchip 产品参考 [系统镜像烧录](./2.flash-img.md)，全志 Sige6 参考 [Sige6 产品文档中的烧录步骤](<../ArmSoM Product/sige6.md>)。
3. 按产品文档接线、上电并登录，系统版本可参考 [查看板卡系统信息](./13.check-board-information.md) 核对。
4. Debian、Ubuntu 或 Armbian 安装软件前，先参考 [更新 APT 软件源](./7.apt-update-sourcelist.md)，检查网络、系统时间和软件源。

## 1.5 开发工具

工具按芯片平台选择，通常运行在用于连接开发板的电脑上。只需下载当前操作用到的工具，无需全部安装。

### 1.5.1 瑞芯微（Rockchip）开发工具

| 工具 | 用途 | 使用场景 |
| --- | --- | --- |
| RKDevTool | 分区镜像或完整固件升级 | 在 Windows 电脑上通过 USB 烧录 |
| RK 驱动助手（DriverAssistant） | 安装 Rockchip USB 驱动 | Windows 电脑首次连接烧录设备时使用 |
| Linux_Upgrade_Tool | 固件升级 | 在 Linux 电脑上通过 USB 烧录 |
| SD_Disk_Tool | 将适用的 Rockchip 固件写入 SD 卡 | 按板型文档制作启动卡或升级卡 |
| FactoryTool | USB 多设备量产烧录 | 批量写入固件 |
| Rockchip 写号工具 | 写入 SN、MAC 地址等信息 | 量产时配置设备标识 |

### 1.5.2 全志开发工具

以下参考 [Sige6 产品文档](<../ArmSoM Product/sige6.md>)。百度网盘路径为 `ArmSoM → ArmSoM-Sige6 → 开发工具`，其中的 Phoenix 系列烧录工具运行于 Windows。

| 工具 | 用途 | 使用场景 |
| --- | --- | --- |
| PhoenixSuit | 分区或完整固件升级 | 通过 USB 将 Sige6 镜像烧录到 eMMC |
| PhoenixCard | 制作 SD 卡固件 | 制作 Sige6 启动卡，按产品文档选择制作模式 |
| PhoenixUSBpro | USB 多设备量产烧录 | 批量写入固件 |
| USB 驱动（`InstallUSBDrv.bat`） | 让 Windows 识别全志 USB 烧录设备 | 使用 PhoenixSuit 前安装 |
| 写号工具 | 写入设备标识信息 | 量产配置，具体操作见配套工具说明 |

### 1.5.3 通用工具

| 工具 | 用途 | 使用场景 |
| --- | --- | --- |
| ADB 工具 | 连接启用 ADB 的系统，执行调试命令或传输文件 | Android 或其他已启用 ADB 服务的镜像 |
| CH340 串口驱动 | 识别采用 CH340 芯片的 USB 转串口设备 | Windows 串口调试；其他芯片需使用对应驱动 |
| 串口终端（如 MobaXterm） | 查看启动日志、登录命令行 | 串口调试；MobaXterm 也可用于 SSH 连接 |
| SDCardFormatter | 格式化 SD 卡 | 整理或重新使用存储卡，本身不负责烧录镜像 |
| IP 扫描工具 | 查找局域网中的设备地址 | 不清楚开发板 IP 时辅助查找 |

:::tip 驱动与终端工具的区别
烧录用 USB 驱动和 USB 转串口驱动用途不同，不能互相替代。串口驱动用于识别串口设备，终端软件用于打开串口；波特率和接线请参考对应板型文档。
:::
