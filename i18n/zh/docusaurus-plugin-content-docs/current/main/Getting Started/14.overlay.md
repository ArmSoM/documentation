# 14. armsom-overlay 配置

<nav className="armsom-doc-shortcuts" aria-label="章节快捷导航"><a href="#doc-section-1">1. 简介</a><a href="#doc-section-2">2. 适用镜像</a><a href="#menu-config">3. 图形化配置</a><a href="#doc-section-3">4. 手动配置</a><a href="#doc-section-4">5. 40-PIN 功能测试</a></nav>

## 1. 简介

设备树 Overlay 在启动时对基础设备树应用增量配置，用于调整引脚复用、启用外设或连接摄像头与显示屏。ArmSoM 提供 `armsom-overlay` 终端图形化菜单，也可直接编辑启动配置文件；两种方式均需重启后生效。

<span id="doc-section-2" className="armsom-section-anchor" />

## 2. 适用镜像

图形化菜单适用于已集成 `armsom-overlay`、采用 `/boot/uEnv/uEnv.txt` 配置方式的 ArmSoM SDK 镜像，包括对应的 Debian 12 和 Ubuntu 22.04 镜像。工具按当前板型读取配置，本节截图以 CM5 为例。

采用 `/boot/firmware/ubuntuEnv.txt` 的 Ubuntu 镜像，以及采用 `/boot/armbianEnv.txt` 的 Armbian 镜像，请使用第 4 章对应的手动方法。是否适用取决于镜像的启动配置方式，不能仅凭发行版名称判断。

<span id="menu-config" className="armsom-section-anchor" />

## 3. 使用 armsom-overlay 图形化配置

### 3.1 打开配置菜单

在板端桌面终端、SSH 或串口终端中执行：

```bash
sudo armsom-overlay
```

以 `root` 登录时可直接执行 `armsom-overlay`，无需安装图形桌面。工具读取 `/boot/uEnv/uEnv.txt` 指向的当前板型配置，列出其中可选的 Overlay；窗口顶部显示实际配置文件名。不同板型的选项以各自配置为准。

  <figcaption className="armsom-image-caption">armsom-overlay 配置菜单（以 CM5 为例）</figcaption>
</figure>

:::tip 找不到命令时
旧镜像可能尚未集成该工具，请使用对应板型已集成 `armsom-overlay` 的新版镜像，或按第 4 章手动配置。仅更新内核不会自动安装这个用户空间工具。
:::

### 3.2 选择需要的外设

`[ ]` 表示未选中，`[*]` 表示选中。先根据产品文档确认外设型号、接口和引脚，再调整选项。

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 在外设列表中移动 |
| 空格 | 勾选或取消当前 Overlay |
| Tab | 在列表与底部按钮之间切换 |
| ← / → | 在底部按钮之间移动 |
| Enter | 执行当前按钮；在列表中按下时转到 Save 按钮，尚未写入配置 |
| Esc | 打开退出确认窗口 |
| F1 / Ctrl+L | 查看帮助 / 调整尺寸并重绘界面 |

底部按钮的作用：**Select** 返回外设列表，**Save** 保存并停留在菜单，**Help** 查看帮助，**Exit** 打开退出确认窗口。

例如，CM5 的 IMX219 接 J25 时选择 `raspberrypi-camera-v2 (imx219-cs0)`；OV13850 接 J12 时选择 `armsom-camera-m1 (ov13850-cs1)`。连接或更换摄像头排线前请先断电；其他板型应按各自接口选择。

:::warning 注意选项含义与引脚复用
勾选 `hdmi-disabled` 或 `dp-disabled` 表示**关闭**对应显示输出。取消某个 Overlay 是移除它的覆盖效果、恢复基础设备树设置，并不总是意味着关闭设备。存在引脚或控制器冲突时不要同时启用；工具仅检查元数据中已声明的冲突，仍需核对板卡引脚说明。
:::

### 3.3 确认保存并重启

1. 选择需要的项目后，按 **Esc**，或选择 **Exit** 并按 Enter，打开 **Review**。
2. 检查变更列表：`Enable` 表示添加 Overlay，`Remove` 表示移除 Overlay。
3. 用左右方向键或 Tab 选择 **OK**，按 Enter 保存尚未保存的改动并退出；选择 **Back** 返回菜单继续编辑。Review 默认选中 Back。

<figure style={{maxWidth: '860px', margin: '1.5rem auto'}}>
  <img src={useBaseUrl('/img/getting-started/armsom-overlay-review.webp')} alt="Review 窗口显示启用 OV13850 摄像头的改动，确认 OK 后保存退出" width="1576" height="837" style={{width: '100%', height: 'auto'}} />
  <figcaption className="armsom-image-caption">核对改动后，选择 OK 保存并退出</figcaption>
</figure>

退出后，在终端执行：

```bash
sudo reboot
```

:::info 保存不等于立即生效
工具通过注释或解除注释当前板型配置中的 `dtoverlay=` 行保存选择，重启后才会应用。**Back 不是撤销**：已通过 Save 保存的内容会保留；如需恢复，请在菜单中改回原来的选择并再次保存。
:::

### 3.4 核对配置与设备

重启后可执行以下只读命令，分别查看已保存的选项、检查配置及对应 DTBO 是否有效：

```bash
sudo armsom-overlay --list
sudo armsom-overlay --check
```

配置检查通过不等于硬件功能测试通过。摄像头可继续使用 [ArmSoM 相机应用](../Advanced%20Manual/2.armsom-camera.md)验证预览，串口等外设按对应产品和接口文档测试。窗口显示不完整时，将终端放大到至少 **80 列 × 20 行**，再按 Ctrl+L 重绘。

## 4. 手动配置 Overlay

### 4.1 Ubuntu22.04镜像启用overlay

- Ubuntu22.04镜像的overlay文件存放于板端的路径：/boot/firmware/dtbs/rockchip/overlay/*.dtbo

- 在 /boot/firmware/ubuntuEnv.txt文件中找到 "overlays=" 这个关键词。如下是为 ArmSoM-Sige7 使用两个覆盖层的示例。

```bash
overlays=armsom-sige7-camera-imx415-4k armsom-sige7-display-10hd
```

​	编辑好之后重启设备来更改overlays设置。



### 4.2 Armbian镜像启用overlay

- Armbian镜像的overlay文件存放于板端的路径：/boot/dtb/rockchip/overlay/*.dtbo

- 在 /boot/armbianEnv.txt 文件中找到或者添加 "overlays=" 这个关键词。如下是为 ArmSoM-Sige7 使用两个覆盖层的示例。

```bash
overlays=armsom-sige7-camera-imx415-4k armsom-sige7-display-10hd
```

​	编辑好之后重启设备来更改overlays设置。

:::tip 

屏幕有显示之后还不能直接用触摸功能，需要加载TP的驱动 

`insmod /lib/modules/6.1.75-vendor-rk35xx/kernel/drivers/input/touchscreen/gt9xx/goodix_gt9xx.ko`
:::

- Armbian镜像可以自己添加overlay文件：
以添加Sige5 UART10功能为例：
```bash
linux-rockchip/arch/arm64/boot/dts/rockchip/overlay$ git remote -v
origin  git@github.com:xxx/linux-rockchip.git (fetch)
origin  git@github.com:xxx/linux-rockchip.git (push)
upstream        git@github.com:armbian/linux-rockchip.git (fetch)
upstream        git@github.com:armbian/linux-rockchip.git (push)
```
将linux-rockchip下载到本地，参考arch/arm64/boot/dts/rockchip/overlay目录下的其他有关串口的dts文件，修改config/sources/families/rk35xx.conf下面的`KERNELSOURCE`为本地代码

### 4.3 ArmSoM-SDK镜像启用overlay
- ArmSoM-SDK镜像的overlay文件存放于板端的路径：/boot/dtb/overlay/*.dtbo
- 打开 /boot/uEnv/uEnv.txt 文件,将复用功能的dtoverlay前的`#`去掉
如下是为 ArmSoM-Sige7 uEnv.txt示例:
```bash
armsom@armsom:/boot$ sudo vi /boot/uEnv/uEnvarmsom-sige7.txt
cmdline="earlyprintk console=ttyFIQ0 console=tty1 consoleblank=0 loglevel=7 roott
wait rw rootfstype=ext4"

enable_uboot_overlays=1
#overlay_start

#40pin
#dtoverlay=/dtb/overlay/rk3588-armsom-can1-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-can1-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c0-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c1-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c3-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c7-m3.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-i2c8-m4.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm2-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm3-m1.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm5-m2.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm6-m2.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm7-m3.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm8-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm12-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm13-m0.dtbo
#dtoverlay=/dtb/overlay/rk3588-armsom-pwm13-m2.dtbo
```
编辑好之后重启设备来更改overlays设置。

## 5. 40-PIN 功能测试

40PIN上的引脚有些一个引脚可以复用多种功能，可以按需配置功能，具体引脚功能可以查看板卡的`40-PIN header`

以sige7上40PIN里面的11、15脚打开串口功能为例：
- 查看系统打开的串口
```bash
root@armsom-sige7:/boot# ls /dev/ttyS*
/dev/ttyS6
```

- 开启 Overlay

11、15脚对应的串口是uart7_m1,对应的overlay文件是/boot/dtb/rockchip/overlay/rk3588-uart7-m1.dtbo。

编辑/boot/armbianEnv.txt文件：
```bash
root@armsom-sige7:/boot# cat armbianEnv.txt
verbosity=1
bootlogo=false
console=both
overlay_prefix=rockchip-rk3588
overlays=rk3588-uart7-m1
fdtfile=rockchip/rk3588-bananapi-m7.dtb
rootdev=UUID=a61c17cd-2e49-4302-879c-6cb86ebf07d1
rootfstype=ext4
usbstoragequirks=0x2537:0x1066:u,0x2537:0x1068:u
```
这里只是添加了`overlays=`这一行。

重启之后配置生效：
```bash
root@armsom-sige7:/boot# ls /dev/ttyS*
/dev/ttyS6 /dev/ttyS7
```

:::tip 

40PIN中的功能默认都是关闭的，需要手动打开才能使用

在/boot/armbianEnv.txt 中加入配置，然后重启 Linux 系统生效

如果只需要打开一个功能，那么就填写一个即可，如果多个功能，在`overlays=`后面用空格隔开
overlays=uart2-m0 uart3-m1 uart4-m2 uart7-m1

类似uart7-m1和uart7-m2不能同时使用
:::
