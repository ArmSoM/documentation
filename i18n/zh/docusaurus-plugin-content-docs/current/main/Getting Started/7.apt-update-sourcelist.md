# 更新 APT 软件源

本指南适用于运行 Debian、Ubuntu 或 Armbian 系统的 ArmSoM 开发板。更新或安装软件包前，请先确认软件源配置可用。

## 开始前准备

- 确认开发板已经连接互联网。
- 使用拥有 `sudo` 权限的账户。
- 修改前先备份当前软件源配置。

```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
```

<span id="doc-section-2" className="armsom-section-anchor" />

## 查看当前软件源

查看主软件源文件和附加软件源目录：

```bash
cat /etc/apt/sources.list
ls -la /etc/apt/sources.list.d/
```

软件源中的发行版代号必须与系统版本一致。可通过以下命令确认：

```bash
. /etc/os-release && echo "$PRETTY_NAME"
```

<span id="doc-section-3" className="armsom-section-anchor" />

## 刷新软件包索引

确认软件源无误后，刷新软件包索引：

```bash
sudo apt update
```

检查命令输出无报错后，再执行系统软件包更新：

```bash
sudo apt upgrade
```

<span id="doc-section-4" className="armsom-section-anchor" />

## 常见问题排查

若 `apt update` 出现仓库错误，先检查网络连接和系统时间，再确认软件源 URL 与 `/etc/os-release` 中的发行版代号一致。

如需恢复原配置：

```bash
sudo cp /etc/apt/sources.list.backup /etc/apt/sources.list
sudo apt update
```

不要混用不同 Debian、Ubuntu 或 Armbian 发行版的软件源，否则可能造成依赖冲突或后续升级失败。

### 刚刷镜像时检查日期和时区 {#fresh-image-apt}

新刷的 ArmSoM SDK 镜像首次启动后，先联网并检查系统时间。若 APT 提示 `Release file ... is not valid yet`，通常是板端时钟早于仓库元数据的生效时间。

```bash
timedatectl status
timedatectl list-timezones
```

时区不正确时，选择实际所在地的时区。以下以中国大陆为例。

```bash
sudo timedatectl set-timezone Asia/Shanghai
sudo timedatectl set-ntp true
timedatectl status
```

如果镜像没有可用的自动校时服务，请对照当前实际时间手动校时。将下面的日期、时间和 UTC 偏移替换为实际值，校准后再运行 `sudo apt update`。

```bash
sudo date -s 'YYYY-MM-DD HH:MM:SS +0800'
```

### Ubuntu 22.04 第三方源卡住

确认 `/etc/apt/sources.list` 包含与当前系统匹配的官方 Ubuntu 源后，本次可临时跳过 `/etc/apt/sources.list.d/`。下面的命令使用 sudo 执行，分别刷新索引和安装缺失的 `python3-venv`。其他依赖有缺失时，可用同样的参数执行原教程的安装命令。

```bash
sudo apt-get -o Dir::Etc::sourceparts=- -o Acquire::Retries=0 -o Acquire::http::Timeout=20 update
sudo apt-get -o Dir::Etc::sourceparts=- install -y python3-venv
```

这些选项只对本次命令生效，软件源文件无需修改。

### Debian 12 预置镜像站无法连接

可临时使用 Debian 官方 HTTPS 源。安装命令以 python3-venv 为例，请替换为当前教程所需的软件包。

```bash
cat > ~/debian-bookworm.list <<'EOF'
deb https://deb.debian.org/debian bookworm main contrib
deb https://deb.debian.org/debian bookworm-updates main contrib
deb https://deb.debian.org/debian-security bookworm-security main contrib
EOF

sudo apt-get -o Dir::Etc::sourcelist="$HOME/debian-bookworm.list" \
  -o Dir::Etc::sourceparts=- update &&
sudo apt-get -o Dir::Etc::sourcelist="$HOME/debian-bookworm.list" \
  -o Dir::Etc::sourceparts=- install -y python3-venv
```
