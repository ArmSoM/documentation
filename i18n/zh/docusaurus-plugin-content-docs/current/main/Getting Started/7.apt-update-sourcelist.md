# 更新 APT 软件源

本指南适用于运行 Debian、Ubuntu 或 Armbian 系统的 ArmSoM 开发板。更新或安装软件包前，请先确认软件源配置可用。

## 开始前准备

- 确认开发板已经连接互联网。
- 使用拥有 `sudo` 权限的账户。
- 修改前先备份当前软件源配置。

```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.backup
```

## 查看当前软件源

查看主软件源文件和附加软件源目录：

```bash
cat /etc/apt/sources.list
ls -la /etc/apt/sources.list.d/
```

软件源中的发行版代号必须与系统版本一致。可通过以下命令确认：

```bash
. /etc/os-release && echo "$PRETTY_NAME"
```

## 刷新软件包索引

确认软件源无误后，刷新软件包索引：

```bash
sudo apt update
```

检查命令输出无报错后，再执行系统软件包更新：

```bash
sudo apt upgrade
```

## 常见问题排查

若 `apt update` 出现仓库错误，先检查网络连接和系统时间，再确认软件源 URL 与 `/etc/os-release` 中的发行版代号一致。

如需恢复原配置：

```bash
sudo cp /etc/apt/sources.list.backup /etc/apt/sources.list
sudo apt update
```

不要混用不同 Debian、Ubuntu 或 Armbian 发行版的软件源，否则可能造成依赖冲突或后续升级失败。
